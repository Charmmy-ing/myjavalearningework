# 【Java｜JavaSE】Java学习日志 Day01-03 - 流程控制与数组入门

本项目基于 Java SE 技术栈搭建，面向 Java 初学者的流程控制练习工程，在基础语法之上新增流程控制与数组练习。

## 核心能力
- 分支结构：if / switch
- 循环结构：for / while、break / continue
- 实战案例：验证码生成、素数查找
- 一维数组与移动操作

## 技术组成
- JDK / Java SE
- 纯 Java 控制台程序

## 目录结构
- day01-helloworld-app：基础语法入门
- day02-basic-app：方法、类型、逻辑、Scanner
- day03：流程控制、循环、数组、算法练习
